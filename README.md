## 先把 Max 本身搞清楚，不然容易被报价绕晕

Anthropic 帮助中心的说法很直接：Max 只有两档，Max 5x 是 $100/月，Max 20x 是 $200/月，目前只提供月度订阅，没有年付。这两个价格是网页订阅价，从 App 内购走，价格会因平台不同而变化。

5x 和 20x 指的是每会话额度相对 Pro 的倍数。每 5 小时重置一次会话额度，另外还有一条跨所有模型的周限额，周限额在每周固定时间重置，跟你的订阅开始时间无关，在 Settings > Usage 里能看到下一次重置时间。

官方同时写明：包括 Max 5x 和 20x 在内，付费计划不提供标准折扣，也没有可以随时索要的优惠码。所以任何声称「官方折扣码」「官方学生价」的说法，都值得先打个问号。

换成实际场景：如果你每天写代码、跑长任务，或者让 Claude 长时间处理大文档，Pro 的额度到下午就见底，Max 5x 是常见的下一跳；只有当你连续几周都被 5x 卡住，$200 那一档才谈得上有性价比。

## 国内用户在充值这一步真正卡住的是三件事

第一件是卡。国内银行发行的 Visa / Mastercard 经常在结算页被直接拒绝，跟卡里有没有额度无关，属于发卡行和商户之间的风控结果。

第二件是环境。地区、账单地址、IP 类型、时区语言指纹，只要有一项对不上，订阅可能开了但很快掉。做代付的教程里反复强调要用住宅 IP（ISP 属性），机场和数据中心 IP 通过率很低，DNS 也不能泄露——这不是玄学，是风控按这几个字段判断你的。

第三件才是账号本身。这条最难受：

> 掉订阅和封号是两回事。掉订阅是支付/续费没走通，账号还在；封号是账号被处理，里面的对话记录一起没。

论坛里讨论代充时出现频率最高的一句话是「包掉订阅，不包封」。这句话本身就是答案。

## 封号、掉订阅、退款：下单前必须问客服的三句话

这部分是全网信息最乱的地方，不同用户的说法互相打架。有的用户说平台「封号质保、掉订阅也质保」，退款扣了一点手续费；也有人转述规则写的是封号后要走官方申诉，申诉成功才退。还有帖子提到退款按 25% 收手续费。

我没法替你确认哪一版是当前有效的，平台规则本身也会改。下任何一单之前，把这三点在客服对话框里问清楚：

1. 账号被封，退不退？按剩余天数退还是按比例扣手续费？
2. 只是掉订阅（账号还在），怎么补？
3. 手续费是固定的还是按比例？退到哪、多久到账？

不管对方怎么答，记住一件事：**保订阅不等于保账号**。任何平台都没能力阻止 Anthropic 处理一个它认为有问题的账号，能承诺的只是掉订阅时的补偿方式。

不适合的情况也说清楚：

## 几个高频问题

**Max 有年付吗？** 没有。官方帮助中心写明 Max 目前只提供月度订阅。

**官方有优惠码吗？** 没有常设折扣。官方明确表示不会应要求发放一次性折扣或优惠券。

**代充能保证账号不被封吗？** 不能，任何渠道都不能。能谈的只有掉订阅和封号之后的处理方式。

**续费怎么安排？** 别等到期当天再处理。提前几天完成续费，中间留出处理失败的缓冲时间，比省那几块钱重要。

**平台显示的价格和官方差多少算合理？** 官方 Max 5x 是 $100/月。第三方报价在这个数字上下浮动属于正常区间；低到明显不合理的那一档，基本都不是同一种渠道，风险也会跟着来。

Claude Max 充值这件事，说到底没有第三个选项：要么你自己把支付环境搭好，走官方 $100 / $200；要么接受溢价，把付款这一步交给第三方。搞清楚自己属于哪一类，比在论坛里继续问「哪家最靠谱」有用得多。
